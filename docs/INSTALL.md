# 安装与运行

## 1. 安装应用

安装 AutoJs6 6.7+、Android 版 QQ 和 Android 版 ChatGPT，并分别完成登录。

## 2. 授予权限

为 AutoJs6 开启：

- 无障碍权限
- 截图或录屏权限
- 文件访问权限
- 后台运行权限

建议关闭系统对 AutoJs6 的电池优化，避免长时间监听被杀死。

## 3. 配置脚本

打开 `src/QQ-ChatGPT-Auto.js`，至少修改：

```js
ownerNickname: "请填写你的QQ昵称"
```

填写的是你在目标聊天中显示的昵称，不是 QQ 号。

## 4. 准备页面

- QQ 停在目标聊天页面
- ChatGPT 停在机器人专用对话底部
- 最近的 `QQBOT_...` 协议回复需要可见
- 不要同时运行两个脚本版本

## 5. 启动

先运行“测试 OCR”。确认识别文字、聊天标题和输入区域正确后，再开始监听。

第一次读取当前画面只建立基线；脚本不会补回启动前的历史消息。

## 6. 停止

在脚本界面点击停止，或按音量上键紧急停止。
