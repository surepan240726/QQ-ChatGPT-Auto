# 故障排查

## 找不到 QQ 输入框

确认 QQ 停在真实聊天页面，而不是联系人资料、搜索、设置或群资料页面。若当前为语音输入模式，脚本会尝试切回文字输入。

## OCR 没有文字

重新授予截图/录屏权限，确认 AutoJs6 内置 ML Kit 可用，并检查聊天文字是否位于脚本识别区域内。

## ChatGPT 页面未确认

打开原来的机器人专用对话并滚动到底部，让最近一条 `QQBOT_...` 回复可见。不要停在项目列表、会话列表或空白新聊天页。

## 找不到发送按钮

QQ 或 ChatGPT 的界面可能已经更新。先按音量上键停止，避免误触，然后查看日志：

```text
/sdcard/AutoJs6/qq_chatgpt_v4.log
```

公开反馈问题前请删除日志中的聊天文字、昵称和请求内容。

## 重复发送或误发

立即按音量上键停止。检查是否同时运行了两个版本、无障碍服务是否卡住，以及输入框在发送后是否正常清空。

## 不能识别或上传图片

这是预期行为。旧版本的图片识别与图片上传功能已经不可用，v0.6.10 已完全删除相关代码。
