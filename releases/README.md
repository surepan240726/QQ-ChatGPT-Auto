# 历史压缩包

这里保存修正文档、注释和版本显示错误后重新打包的历史版本。正式下载入口在 [GitHub 发布页](https://github.com/surepan240726/QQ-ChatGPT-Auto/releases)，请在对应版本的 **Assets** 中选择 `QQ-ChatGPT-Auto-v版本号.zip`。

历史版本标签指向当前仓库快照，GitHub 自动生成的 `Source code (zip)` 不是对应的旧版脚本。

- 历史版本只用于回溯和研究
- v0.6～v0.6.6 的图片识别与图片上传功能现已不可用
- 日常使用请下载 v0.6.10
- 压缩包不包含日志、群聊截图、账号信息或聊天记录
